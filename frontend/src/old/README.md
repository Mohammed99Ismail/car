# مجلد المراجع وقوالب Yummy القديمة (Yummy Template Reference Archive)

هذا المجلد مخصص لاحتواء كافة المكونات، الصفحات، النماذج، ومخازن البيانات (Stores) التابعة لقالب **Yummy** الأصلي والتي **لا تُستخدم** حالياً في نظام إدارة معرض السيارات (Car Showroom Management System).

تم فصل هذه الملفات هنا عمداً لتكون **كمرجع تصميمي وكودي (Reference)** يمكن العودة إليه عند الحاجة لأي ميزة أو رسم بياني مستقبلاً، مع إبقاء كود النظام الأساسي نظيفاً ومنفصلاً تماماً.

---

## هيكل المجلد (Folder Structure)

```
frontend/src/old/
├── assets/              # الصور والملفات الرسومية التوضيحية للقالب (3d-female-character-waving.png)
├── common/              # الدوال المساعدة والتحقق القديمة (validations, cn)
├── components/          # مكونات واجهة المستخدم غير المستخدمة (Charts, Orders, Products, CustomIcons, UI, Category, etc.)
├── composables/         # دوال التركيب المساعدة التابعة للرسوم البيانية والقالب (useFilter, إلخ)
├── locales/             # ملفات اللغات غير المستخدمة (fa.yml, zh.yml)
├── mocks/               # معالجات المحاكاة (Mock Handlers) الخاصة بالقالب
├── models/              # نماذج البيانات والواجهات (TypeScript Interfaces/Types) الخاصة بالقالب
├── modules/             # الموديولات غير النشطة مثل pwa.ts
├── pages/               # الصفحات التوضيحية للقالب (Apps, Brands, Categories, Colors, Invoices, etc.)
├── services/            # الخدمات البرمجية الخاصة ببيانات القالب التجريبية (report.service.ts, إلخ)
└── store/               # مخازن بينيا الخاصة ببيانات المتجر والقالب (brand, category, product, chat, etc.)
```

---

## ملاحظات هامة للمطورين (Important Notes)

1. **الاستبعاد من الـ Build و الـ TypeScript:**
   - تم استبعاد هذا المسار في `tsconfig.json` لضمان عدم إبطاء فحص الأنواع أثناء البناء والتطوير.
2. **التوجيه التلقائي (Routing):**
   - نقل هذه الصفحات إلى `src/old/pages/` يمنع مكتبة `vite-plugin-pages` من إنشاء مسارات غير مرغوب فيها في الروابط الحية للنظام.
3. **عدم التعديل العشوائي:**
   - يرجى عدم استيراد مكونات من هذا المجلد مباشرة داخل كود النظام النشط. إذا رغبت في استخدام أي مكون أو رسم بياني، قم بنقله أو نسخ الكود المطلوب إلى المسار النشط المناسب (`src/components/`, `src/pages/`, إلخ) ومواءمته مع معايير النظام.
